# ✨ Features

### Shopping & Checkout
- **Interactive Checkout Flow**: Step-by-step shipping address input, payment provider selection (Credit Card, PayPal, Express Pay), and live credit card visual updates.
- **Dynamic Cart Management**: Real-time total, tax, and discount calculations with item quantity controls.
- **Order Summary Analytics**: Detailed item breakdown with instant status indicators and SSL security badges.

### Authentication & Security
- **Multi-Method Sign-In**: Toggle between Email/Password and Mobile Phone sign-in options.
- **6-Digit OTP Verification**: Auto-advancing numeric input fields for seamless SMS authentication.
- **Google OAuth Integration**: Ready-to-connect social authentication flow.

### Design & Customization
- **Tailwind v4 Tokenized Theme Engine**: Runtime theme switching using CSS `@theme` definitions and `data-theme` attributes (`okc`, `emerald`, `sapphire`, `violet`, `dark`).
- **Signature Matte UI**: Dark charcoal aesthetic inspired by OKC Media Matte Coral design tokens.
